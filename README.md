# HELLSING ARCHIVE — Django

Фан-архив по Hellsing с раздельными линиями:
- оригинальная манга;
- Hellsing / «Война с нечистью» (TV 2001, 13 серий);
- Hellsing Ultimate (10 OVA);
- The Dawn;
- персонажи и сравнение образов;
- сюжет;
- двуязычные цитаты.

## Запуск
```powershell
py -m pip install -r requirements.txt
py manage.py migrate
py manage.py runserver
```

## Важно про изображения
В демо-архиве используются удалённые reference/key-art изображения. Перед публичным размещением замени их на изображения, права на которые у тебя есть, или храни локальные разрешённые материалы в `static/images/`.


## Обновление архива
- Сюжет разделён на мангу, TV 2001 и Ultimate.
- Добавлены подробные карточки всех 13 серий TV и 10 OVA Ultimate.
- Страница персонажа позволяет выбрать конкретную версию и показывает историю только этой версии.
- Убрана зависимость публичных страниц от таблиц Quote/GalleryItem, поэтому старый `db.sqlite3` больше не вызывает `no such table: main_quote`.
- Для отсутствующих оригинальных визуалов используется заглушка вместо повторного постера или косплея.
- Цитаты хранятся отдельно с английской и русской строкой и фильтром по версии.
